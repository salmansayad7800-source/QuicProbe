# QuicProbe

QuicProbe is a Pure Python cybersecurity tool for scanning QUIC/HTTP3 indicators and analyzing suspicious authentication activity from security logs.

It provides a lightweight command-line workflow for defensive analysis, log inspection, and risk classification, without requiring third-party dependencies.

## Highlights
- QUIC and HTTP/3 pattern detection
- Security log parsing for failed login attempts
- Suspicious IP identification
- Risk classification (low, medium, high)
- JSON, CSV, and HTML report export
- File and directory scanning support
- No external libraries required

## Use Cases
- Security audit support
- Log review and threat hunting preparation
- QUIC/HTTP3 indicator inspection
- Educational and research cybersecurity projects
