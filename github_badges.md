# GitHub Badges / Shields

You can use these badges in the project README for a more professional GitHub appearance.

```md
![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Status](https://img.shields.io/badge/Status-Active-success)
![Security](https://img.shields.io/badge/Security-Analysis-orange)
![PurePython](https://img.shields.io/badge/Pure-Python-9cf)
```

```md
# QuicProbe
```
